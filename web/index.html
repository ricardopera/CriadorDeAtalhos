🔗 Criador de Atalhos

Versão Web - Execute diretamente no seu navegador

Selecione um arquivo ou pasta para criar o atalho.

ℹ️ Como usar a versão Web

  • Arquivo .lnk: Baixa um arquivo de atalho do Windows que você pode colocar onde quiser
  • Script VBS: Gera um script que você pode executar para criar o atalho automaticamente
  • Limitações do navegador: Por segurança, o navegador não pode acessar arquivos diretamente. Cole o caminho completo ou use a seleção de arquivos
  • Área de transferência: Funciona apenas em navegadores modernos com HTTPS
